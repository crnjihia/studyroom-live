Mathematical Invariant

Drift-Free Relative Position Comment Anchoring

Standard document editors anchor comments to numeric string offsets (e.g. chars 37–86), causing comments to drift onto wrong text whenever preceding paragraphs are edited. StudyRoom Live binds comment anchors directly to CRDT Item IDs via Y.RelativePosition.

Classic Numeric Index Anchoring

Prone to Anchor Drift

Stores fixed character range [37, 86] in database. When text is inserted before the target, the highlight detaches or drifts onto unrelated words.

StudyRoom Live RelativePosition

Drift-Free Mathematical Anchor

Stores Y.createRelativePositionFromTypeIndex tuple. The anchor tracks the underlying CRDT Node ID regardless of preceding text additions or deletions.

Durability & Storage

SHA-256 Snapshot Deduplication & Visual LCS Diff

The collab server triggers a 30-second autosave heartbeat. If the document state update hash matches the latest snapshot in PostgreSQL, redundant writes are skipped. Modified states commit a new version with word-level LCS visual diffing.

    Developer Setup

    Local Development Quickstart

    Run StudyRoom Live locally in under 3 minutes using Docker Compose and npm workspaces.

    1
    Clone the Repository & Install Dependencies
    StudyRoom Live is structured as an npm monorepo with web, collab-server, and shared workspaces.
    git clone https://github.com/crnjihia/draftroom-live.git && cd draftroom-live && npm install
    2
    Start PostgreSQL & Redis Infrastructure
    Spin up PostgreSQL 16 on port 5432 and Redis 7 on port 6379 via Docker Compose.
    docker compose up -d db redis
    3
    Generate Prisma Client & Push Database Schema
    Initialize relational tables for documents, snapshots, and threaded comments.
    npm run prisma:generate && npm run prisma:migrate
    4
    Launch Concurrent Development Services
    Starts both the Hocuspocus collab server (:1234) and the Next.js 14 web app (:3001).
    npm run dev
